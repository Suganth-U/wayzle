# Wayzle 🗺️

Wayzle is a modern, real-time navigation and place discovery app built with Expo, React Native, and Supabase.

## Features
- **Discovery Feed**: Find top-rated and trending places around you or in a marked area.
- **Real-Time Navigation**: Turn-by-turn navigation with dynamic routing using OpenRouteService.
- **Google Places Integration**: View detailed place information, photos, opening hours, and reviews.
- **Anonymous Reviews**: Post reviews and ratings anonymously directly from the app.
- **Cross-Platform**: Works smoothly on Web, iOS, and Android using Expo and MapLibre.

## Tech Stack
- React Native & Expo
- TailwindCSS (NativeWind)
- Supabase (Auth, Database, Storage)
- Google Places API
- OpenRouteService API
- MapLibre GL

## Quick Start
1. Clone the repository
2. Install dependencies: `npm install`
3. Run the app: `npx expo start`
